## Original Wallpaper

The shipped purple variant `wallpaper-purple.webp` was edited with the built-in image generator after the user requested purple instead of orange. Edit prompt: Preserve the exact folded black graphite architectural shapes, composition, deep charcoal background, and texture. Change all emerald/green luminous edge highlights and all orange/coral reflections to restrained purple and violet highlights consistent with the Prystech logo's #9B32FA violet and #CB8DFA lavender. Keep everything else unchanged. No text, new shapes, logos, green, or orange.

`wallpaper.webp` is an optimized locally bundled derivative of the original image generated with the built-in `image_gen` tool.

Prompt: Create a premium original Linux computer desktop wallpaper, 16:9 landscape. Full bleed abstract folded black graphite architectural ribbons, like a single angular sculptural continuous folded ribbon across the right half of the image. Narrow restrained luminous emerald green edges and a very small muted coral reflection. Dark near-black charcoal background with very subtle fine grain. Refined product photography of black anodized metal, tactile matte material, sculptural folds and crisp geometric details. Left 55 percent very quiet dark charcoal negative space for terminal windows, ribbon occupies right 45 percent and gently passes into the lower center. Understated sophisticated Linux workstation aesthetic, not neon hacker style. No orbs, no text, no letters, no symbols, no logo, no interface, no rounded blobs. Restrained lighting, visible details in the right-side ribbon. Save as a landscape wallpaper.

## Icons and Fonts

- Sequel Sans Roman Body and Medium Body are the exact font assets used by `prystech.co`, incorporated at the user's request: https://prystech.co/assets/fonts/Sequel%20Sans%20Roman%20Body.otf and https://prystech.co/assets/fonts/Sequel%20Sans%20Medium%20Body.otf . The desktop UI and public gallery use Sequel Sans; terminal content retains JetBrains Mono.

- Lucide 0.468.0: https://unpkg.com/lucide@0.468.0/dist/umd/lucide.min.js ; ISC license, see `licenses/lucide.txt`.
- Inter, Latin variable subset, Google Fonts: https://fonts.google.com/specimen/Inter ; SIL Open Font License, see `licenses/inter.txt`.
- JetBrains Mono, Latin variable subset, Google Fonts: https://fonts.google.com/specimen/JetBrains+Mono ; SIL Open Font License, see `licenses/jetbrains.txt`.

The user supplied `PrystechHeaderLogo.svg` from their Downloads folder. `prystech-logo.svg` preserves that original vector artwork unchanged. `favicon.svg` isolates its original purple symbol paths with the original gradients. These assets are used in the system bar, wallpaper wordmark, startup/power screens, terminal, and About app.
